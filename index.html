P Pictail

Put the details on the picture.

Install it on a phone or PC from the browser. No App Store. No Play Store. It is a website that can live on the home screen.

Keep it without an app

  • iPhone / iPad: Safari → Share → Add to Home Screen.
  • Android: Chrome menu → Install app or Add to Home screen.
  • Windows / Mac: Chrome or Edge menu → Install Pictail. Opens in its own window.
  • Offline copy: Download ZIP, unzip, open index.html. Photos still need internet.
